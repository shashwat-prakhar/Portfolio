# Shashwat Prakhar — Developer Portfolio

A responsive dark-themed React portfolio focused on cybersecurity, cloud security, AI and machine learning.

## Run locally

Requirements: Node.js 18+

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

The production site is generated in `dist/`.

## Before publishing

Update these placeholders in `src/App.jsx`:
- Replace the LinkedIn placeholder URL with your actual profile.
- Replace `YOUR_EMAIL@example.com` with your professional email.
- Add your resume PDF to `public/` and add a visible resume download link if you want one.
- Verify each project description, technology list, and repository URL against the current repository.
- Add only skills and claims you can explain in an interview.

## Deploy

1. Push this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Use `npm run build` as the build command and `dist` as the output directory.
4. Deploy.

No backend or environment variables are required for this static portfolio.
